## Run the grading checks

The grading script checks that the required files exist and that the
repository is clean. It cannot tell whether your scripts draw recognizable
letters or whether the screenshot shows both letters in distinct colors;
course staff grade those.

From the repository root on the VM:

```bash
pytest -v
```

Failures are expected while the lab is incomplete. Fix every failure before
the final push.
